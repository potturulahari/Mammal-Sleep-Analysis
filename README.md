# 🐾 Mammal Sleep Analysis Dashboard | Power BI

## 📌 About This Project

This is my first dashboard created using Microsoft Power BI. I worked on this project while learning data visualization and wanted to understand how raw data can be turned into meaningful visuals.

For this project, I used a dataset containing information about mammal sleep patterns, body weights, and danger levels.

My main goal was to explore the data, understand the relationships between different variables, and present the information in a simple and easy-to-understand dashboard.

## 🛠️ Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis

## 📊 What I Created

I used different visualizations to explore the dataset:

- **KPI Card:** To display the average sleep duration of mammals.
- **Scatter Plot:** To understand the relationship between body weight and sleep duration.
- **Bar and Column Charts:** To compare different sleep-related measurements.
- **Slicer:** To filter the data based on danger levels.

## 🎯 What I Learned

Since this was my first Power BI project, it helped me understand:

- How to create a dashboard from a dataset.
- How to choose different charts based on the data.
- How to create KPI cards to highlight important values.
- How to use slicers to make dashboards interactive.
- How to organize visuals so that information is easy to understand.
